✨ SnapMark 设置

配置视觉大模型后，截图就能直接提取文字、解释报错、翻译、转表格。

AI 服务

选完仍需自行填写 API Key。本地 Ollama 无需 Key，填任意字符即可。

需兼容 OpenAI /chat/completions 接口，注意结尾要带 /v1。

只保存在这台电脑的本机存储里（storage.local），不会同步到云端，也不会发给除你填写的服务商以外的任何地方。

必须是支持图片输入的视觉模型，纯文本模型（如 deepseek-chat）会报错。

越低越稳定，OCR 建议 0~0.3。

长表格/长文翻译可调大。

会追加到每次请求的 system prompt 后面。

快捷键

Alt+Shift+S区域截图
Alt+Shift+A截图并直接问 AI
Alt+Shift+F整页截图
Esc取消 / 关闭
Ctrl+Z撤销标注

想改快捷键？打开 chrome://extensions/shortcuts（Edge 为 edge://extensions/shortcuts）。

使用提示

  • 先用箭头或矩形圈出重点，再点 AI 按钮 —— 标注会一起发给模型，回答更聚焦。
  • 截图会等比压缩到长边 1600px 再上传，省 token 也更快。
  • AI 面板里的 ➕ 可以把回答直接写回图片上，方便截图分享。
  • 浏览器内置页（chrome://、扩展商店、PDF 阅读器）无法注入脚本，属于浏览器限制。
